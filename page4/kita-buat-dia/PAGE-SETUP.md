# Kita Buat Dia · persediaan Facebook Page

Panduan untuk Irfan selepas semakan editorial. Nama menu di bawah mengikut paparan Inggeris. Jika Facebook memaparkan label BM atau susunan lain, cari nama medan yang sepadan.

## Teks untuk disalin

**Nama Page** · Kita Buat Dia  
**Kategori utama** · Digital creator  
**Bio (87 aksara)** · Din cuba baiki benda yang menyusahkan kita hari-hari. Tengok apa jadi dalam bengkel 3D.

**About / Perihal**

Bengkel Din bermula di anjung rumah teres. Bila hujan, baju terpaksa berhimpit. Bila balik kampung, ais bekal pula cepat cair. Din ambil satu masalah daripada isu semasa Malaysia, cuba satu binaan, kemudian ubah bahagian yang tersangkut. Korang boleh ikut ujian dari dalam model.

## Senarai semak Irfan

1. [ ] Pada komputer, log masuk menggunakan profil Irfan yang akan mentadbir Page. Dari menu Facebook pilih **Pages → Create new Page**, atau buka borang penciptaan terus. [Borang Facebook](https://www.facebook.com/pages/create) · [Panduan penciptaan Meta](https://en-gb.facebook.com/business/learn/lessons/how-create-facebook-business-page)
2. [ ] Dalam **Page name**, masukkan **Kita Buat Dia**. Taip **Digital creator** dalam **Category** dan klik cadangan yang sepadan. Jika pilihan setempat berbeza, cuba **Video creator**. Tampal bio di atas dalam **Bio**. Baca pratonton untuk ejaan dan jarak, kemudian klik **Create Page**.
3. [ ] Dalam langkah **Finish setting up your Page**, langkau alamat, waktu operasi, laman web, nombor telefon dan WhatsApp. Tiada butiran hubungan awam dibekalkan. Jika Irfan sediakan e-mel editorial kelak, masukkan melalui **About → Contact and basic info → Edit → Save**. Untuk pertanyaan sekarang, gunakan Messenger. Pada Page, buka menu **… → Add/Edit action button → Send message → Save** jika tersedia. Semak butang dari pandangan pelawat.
4. [ ] Klik gambar profil kanan atas → **See all profiles → Kita Buat Dia**. Pada muka Page, pilih **About → Details about you → Write some details about yourself** atau medan **Description** jika tersedia. Tampal perenggan About dan simpan. Sesetengah paparan hanya menawarkan Bio. Dalam keadaan itu, kekalkan bio pendek dan catat bahawa medan panjang belum tersedia.
5. [ ] Dengan identiti Page masih aktif, pilih **Settings & privacy → Settings → Page setup → Name → Username → Edit**. Cuba `@kitabuatdia`, `@kitabuatdiamy`, `@kitabuatdiabengkeldin` mengikut turutan. Taip tanpa `@` jika medan menambahkannya. Klik **Save changes** selepas Facebook menerima nama. Ketersediaan handle dan laluan pada akaun Irfan **(perlu semak)**. Jika medan belum tersedia, teruskan dengan URL bernombor.
6. [ ] Selepas karya diluluskan, klik kamera pada avatar → **Upload photo → Save**. Klik **Edit cover photo → Upload photo → Reposition → Save changes**. Buka URL awam melalui telefon dan komputer, periksa potongan avatar, tajuk, bio, Perihal dan butang mesej. Salin URL sebenar dan ID daripada **About → Page transparency → See all** atau tetapan maklumat Page.
7. [ ] Pada aplikasi Facebook telefon, pilih gambar profil → **See all profiles → Kita Buat Dia** → buka Page → **Professional dashboard → Monetization → Content Monetization**. Lihat status, sekatan polisi, jemputan atau borang minat. Jika Irfan mahu memohon dan borang tersedia, pilih borang, semak butiran, hantar dan catat pengesahan. Jika menu tiada, semak identiti aktif dan **Meta Business Suite → Monetization** untuk Page sama, kemudian rekod “menu tiada” bersama tarikh. Meta menerangkan akses melalui jemputan. [Arahan Meta, dikemas kini November 2026](https://about.fb.com/news/2026/03/creator-fast-track-grow-your-audience-earn-money-on-facebook/)
8. [ ] Rekod untuk **SME-MY** sahaja. Tarikh MYT ___ · Page ID ___ · handle / URL awam ___ · status tepat pada skrin ___ · sekatan atau tindakan berikutnya ___. Semak semula selepas jemputan atau perubahan status. Catat pengaktifan, pendapatan terakru dan bayaran diterima secara berasingan.

## Brief karya untuk dijana kemudian

- **Palet.** Biru bengkel `#213E4B` pada baju Din, kuning pita ukur `#F4BA49` untuk tanda ujian, tanah liat `#AD5B3F` pada apron dan krim kertas `#FFF4DB` untuk huruf.
- **Fon.** [Oswald Bold](../../assets/fonts/Oswald-Bold.ttf) untuk nama dan tajuk bengkel. [Montserrat Bold](../../assets/fonts/Montserrat-Bold.ttf) untuk sari kata BM, terutama nombor dan unit.
- **Logo.** Atas bulatan biru bengkel, buka pembaris lipat kuning menjadi huruf K menggunakan tiga ruas dan dua titik pangsi tanah liat. Garisan putih pendek pada ruas panjang memberi bacaan pembaris. Siluet mesti terbaca pada 48 px. Elakkan tanda skala halus dan teks pada avatar.
- **Sampul.** Induk 1640 × 720. Pada paras meja, Din di kiri tengah sedang merenggangkan dua penyangkut. Di kanan tengah, potongan rak menunjukkan lengan baju dan benang ujian di celahnya. Cahaya petang menyapu serat kayu, latar anjung biru redup. Nama Page di atas ruang kosong antara kepala dan rak, “Bengkel Din” di bawahnya. Simpan tangan, benang dan nama dalam 60% tengah, kosongkan bucu kiri bawah. Rupa Din mengikut [brief watak](STYLE.md#din).
