## Senarai semak Irfan

1. [ ] Pada komputer, log masuk menggunakan profil Irfan yang akan mentadbir Page. Dari menu Facebook pilih **Pages → Create new Page**, atau buka borang penciptaan terus. [Borang Facebook](https://www.facebook.com/pages/create) · [Panduan penciptaan Meta](https://en-gb.facebook.com/business/learn/lessons/how-create-facebook-business-page)
2. [ ] Dalam **Page name**, masukkan **Di Belakang Tabir**. Taip **Education** dalam **Category** dan klik cadangan yang sepadan. Jika pilihan setempat berbeza, cuba **Digital creator**. Tampal bio di atas dalam **Bio**. Baca pratonton untuk ejaan dan jarak, kemudian klik **Create Page**.
3. [ ] Dalam langkah **Finish setting up your Page**, langkau alamat, waktu operasi, laman web, nombor telefon dan WhatsApp. Tiada butiran hubungan awam dibekalkan. Jika Irfan sediakan e-mel editorial kelak, masukkan melalui **About → Contact and basic info → Edit → Save**. Untuk pertanyaan sekarang, gunakan Messenger. Pada Page, buka menu **… → Add/Edit action button → Send message → Save** jika tersedia. Semak butang dari pandangan pelawat.
4. [ ] Klik gambar profil kanan atas → **See all profiles → Di Belakang Tabir**. Pada muka Page, pilih **About → Details about you → Write some details about yourself** atau medan **Description** jika tersedia. Tampal perenggan About dan simpan. Sesetengah paparan hanya menawarkan Bio. Dalam keadaan itu, kekalkan bio pendek dan catat bahawa medan panjang belum tersedia.
5. [ ] Dengan identiti Page masih aktif, pilih **Settings & privacy → Settings → Page setup → Name → Username → Edit**. Cuba `@dibelakangtabirmy`, `@dibelakangtabirmalaysia`, `@dibelakangtabir3d` mengikut turutan. Taip tanpa `@` jika medan menambahkannya. Klik **Save changes** selepas Facebook menerima nama. Ketersediaan handle dan laluan pada akaun Irfan **(perlu semak)**. Jika medan belum tersedia, teruskan dengan URL bernombor.
6. [ ] Selepas karya diluluskan, klik kamera pada avatar → **Upload photo → Save**. Klik **Edit cover photo → Upload photo → Reposition → Save changes**. Buka URL awam melalui telefon dan komputer, periksa potongan avatar, tajuk, bio, Perihal dan butang mesej. Salin URL sebenar dan ID daripada **About → Page transparency → See all** atau tetapan maklumat Page.
7. [ ] Pada aplikasi Facebook telefon, pilih gambar profil → **See all profiles → Di Belakang Tabir** → buka Page → **Professional dashboard → Monetization → Content Monetization**. Lihat status, sekatan polisi, jemputan atau borang minat. Jika Irfan mahu memohon dan borang tersedia, pilih borang, semak butiran, hantar dan catat pengesahan. Jika menu tiada, semak identiti aktif dan **Meta Business Suite → Monetization** untuk Page sama, kemudian rekod “menu tiada” bersama tarikh. Meta menerangkan akses melalui jemputan. [Arahan Meta, dikemas kini November 2026](https://about.fb.com/news/2026/03/creator-fast-track-grow-your-audience-earn-money-on-facebook/)
8. [ ] Rekod untuk **ED-MY** sahaja. Tarikh MYT ___ · Page ID ___ · handle / URL awam ___ · status tepat pada skrin ___ · sekatan atau tindakan berikutnya ___. Semak semula selepas jemputan atau perubahan status. Catat pengaktifan, pendapatan terakru dan bayaran diterima secara berasingan.

## Brief karya untuk dijana kemudian

- **Palet.** Biru dakwat `#18313C` untuk latar, hijau air `#32B8A5` untuk satu aliran aktif, konkrit `#A29A88` untuk permukaan potong dan putih kapur `#FAF8EF` untuk huruf. Kekalkan warna asli tanah, air dan objek.
- **Fon.** [Montserrat Bold](../../assets/fonts/Montserrat-Bold.ttf) untuk nama dan sari kata. Huruf biasa bercampur besar dan kecil, seperti label di muzium.
- **Logo.** Kanvas segi empat 1:1. Di tengah bulatan biru dakwat, bina satu blok konkrit dalam unjuran tiga suku. Potong suku hadapan hingga nampak satu saluran hijau berbentuk siku menembusi dua muka. Tinggalkan ruang kosong sebesar diameter saluran di keliling bentuk. Pada saiz 48 px, siku itu mesti masih kelihatan bersambung. Logo tanpa huruf.
- **Sampul.** Sediakan induk landskap 1640 × 720. Dari kiri ke kanan, air dari bumbung rumah teres turun ke longkang di bawah kaki lima, kemudian muncul di mulut paip. Satu keratan memanjang menyambungkan ketiga-tiganya. Letak nama Page dan baris kecil “Dalam Benda” pada dinding gelap di tengah atas. Simpan saluran utama dan tajuk dalam 60% tengah. Biarkan bucu kiri bawah lapang untuk tindihan avatar.
