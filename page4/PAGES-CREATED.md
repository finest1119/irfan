## Semakan monetisation — 28 November 2026 (MYT)

Irfan menetapkan Facebook Content Monetisation sebagai fokus semasa untuk **Di Belakang Tabir** dan **Kita Buat Dia**. Atas keputusan Irfan, Shopee Affiliate kekal tidak disambungkan pada kedua-dua Page.

### Di Belakang Tabir

Semakan melalui Dashboard Facebook → Monetisation dengan identiti Page ini aktif.

| Program | Status dan tindakan disahkan |
| --- | --- |
| Content monetisation | `Invitation only`. Pilihan `Notify me` ditekan dan Facebook mengesahkan `Notification reminder set`. Tiada jemputan, borang waitlist atau butang pengaktifan dipaparkan dalam panel ini. |
| Stars | 1 daripada 3 kriteria dipenuhi. Negara layak. Kemajuan pengikut 0/500 dan tempoh mengekalkan 500 pengikut ialah 0/30 hari berturut-turut. Peringatan kelayakan disahkan. |
| Subscriptions | 2 daripada 3 kriteria dipenuhi. Syarat umur dan negara dipenuhi. Kemajuan pengikut 0/5,000. Peringatan kelayakan disahkan. |
| Branded content tag | Diaktifkan melalui `Enable Tag` dan `Confirm`. Facebook mengesahkan Page boleh melabelkan perkongsian berbayar. |
| Affiliate partnerships | Layak untuk setup. Shopee dan Lazada dipaparkan sebagai `Not connected`. Facebook menyenaraikan Lazada sebagai `Mobile app only`. |
