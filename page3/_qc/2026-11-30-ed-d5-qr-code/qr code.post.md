# A QR Code Can Still Scan With Part of It Missing

**Keyword / filename:** qr code

## Facebook caption

Scratched, smudged, or torn, a QR code often still works. Those little squares hold your link plus extra recovery data worked out with clever math, so if part of the code is covered your phone fills in the gaps. At the highest setting, up to about 30 percent can be restored. The three big corner squares help your camera find the code and line it up, even upside down, so cover one of those and the scan can fail. Do you scan QR codes, or type the link yourself?
